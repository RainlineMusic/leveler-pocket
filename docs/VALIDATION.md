# Проверки Level Pocket 0.2.0 — 2026-10-07

## DSP

Portable C++17 suite: PASS. GCC -Wall -Wextra -Wpedantic -Werror: сборка PASS. AddressSanitizer + UndefinedBehaviorSanitizer: PASS; LeakSanitizer отключён из-за ограничений среды.

Проверены:

- Плавная спектральная форма без выступов оставляет RMS без коррекции.
- Выступающий пик уменьшает управляющий уровень.
- Масштабирование на +6 dB сдвигает детектор на +6 dB.
- Spectral=0 точно возвращает обычный RMS.
- Стандартная ratio/knee характеристика, Ratio=1, отпускание в тишине.
- Связанный stereo gain без отмены детектора на противофазе.
- Bypass исключает Output trim; NaN/Inf санитизируются.
- 44.1, 48, 88.2, 96, 176.4, 192 кГц.
- Установившийся результат при старте сразу с субтона совпадает с результатом после плотной фразы (допуск 0.00001 dB).
- Reset и повторный старт плотного звука дают тот же детектор после установления коротких огибающих.

## Измеренный пример

Spectral=100%, Threshold=−24 dBFS, Ratio=4:1, Knee=6 dB. Оба сигнала имеют RMS около −19.99 dBFS.

| Сигнал | Детектор | Gain reduction |
|---|---:|---:|
| Плотный harmonic fixture | −20.567 dB | −2.607 dB |
| Субтоновый harmonic fixture | −21.805 dB | −1.710 dB |

F0=125 Гц, 60 гармоник, амплитуды h^-1.15. В субтоне первые две гармоники умножены на 2, остальные на 0.3. Каждый сигнал отдельно нормализован до RMS=0.1. Это искусственная модель без формант, дыхания и фонетики.

Разница детектора около 1.24 dB, уменьшение компрессии около 0.90 dB. Эффект умеренный: тест не подтверждает полное устранение ложного срабатывания и не доказывает качество на реальном вокале. Предыдущая версия с выученным профилем давала на этой модели большую разницу, но зависела от выбора эталона; здесь это состояние удалено.

## Сборка и интерфейс

- JUCE 8.0.4, GNU C++13, Linux x86_64: VST3 успешно собран и слинкован.
- JUCE integration test: PASS — mono/stereo, roundtrip параметров состояния, host bypass, нулевая заявленная аудиолатентность.
- Снимки UI: Dark/Neon/Amber при ширине 500/800/1200 px; визуально проверены Dark 800 и Amber 500.
- CMake/CTest portable suite: PASS. Оба GitHub workflow прошли разбор YAML.
- Снимки использовали синусоидальный тестовый сигнал. Изолированный тон может быть сильно подавлен в детекторе как спектральный выступ; это не свидетельствует о верной реакции на естественный голос.

## Ограничения проверки

Реальные записи вокала, субъективное выравнивание громкости, DAW transport/automation stress, pluginval и native Windows/macOS/AAX пока не проверены в этой поставке. GitHub Actions не запускались удалённо. Отдельная проверка патентной свободы не выполнялась.

Ключевые ограничения алгоритма и точные коэффициенты приведены в DETECTOR-MATH.md.
